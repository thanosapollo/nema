# Security policy

Nema is alpha software. Current builds do not implement end-to-end encryption. Legacy and modern OMEMO support is planned, not available yet; do not use current builds when end-to-end encryption is required.

Report security problems privately to `public@thanosapollo.org`. Include the affected commit, Android version, and enough detail to reproduce the issue. Please do not open a public issue for an undisclosed vulnerability.

Only the current `master` branch receives security fixes.
