#+TITLE: Nema changelog

* 0.3.0 — 2026-09-23

Third alpha release.

+ Add persistent named threads and an in-chat switcher for Main and thread destinations in direct chats and rooms.
+ Add experimental shared thread names through an optional server directory. Shared names require a supporting server; this is not a general XMPP interoperability claim.
+ Retain drafts, uploaded attachments, and reply/edit state across conversation switches. Show retained attachments and allow attachment-only sends.
+ Preserve conversation scroll positions and keep delayed sends, typing, and thread actions tied to their originating account and destination.
+ Keep cached conversations visible during refresh and move history indexing, snapshot comparison, and visible-read preparation off the UI thread.
+ Add controls for loading older direct and room history, with retry and end-of-history states. Direct history uses account-wide archive pages, so sparse conversations may need repeated requests.
+ Limit local read marking to displayed messages and restrict synchronized read state to the user's own activity.
+ Retry transient archive failures, preserve repeated account archive records, and repair authenticated room archive duplicates and message corrections.
+ Require current room membership before sending queued group messages or requesting room archives; allow failed joins to be retried.
+ Open notification targets under the correct account and prevent touches in an open conversation from reaching the Home screen underneath.
+ Route onion-account messaging and attachments through Orbot without direct fallback. Verified same-onion message connections may omit XMPP TLS only when the server offers none; offered TLS must validate and attachments still require HTTPS. Update checks remain direct HTTPS, and external links follow the browser's routing.
+ Ask before resetting a recognized incompatible alpha database. Resetting deletes local messages and drafts; newer or unrecognized databases are not automatically erased.
+ Fix update installer handoff on Android versions with package visibility restrictions.
+ Restore the Cut & wind launcher artwork, including round and themed icons.

This release does not implement end-to-end encryption. Tor routing is not end-to-end message encryption.

* 0.2.0 — 2026-08-30

Second alpha release.

+ Add automatic release checks and a Settings journey for downloading, verifying, and installing updates.
+ Verify update package identity, increasing version, checksum, and Android signing lineage before installer handoff.
+ Preserve direct-message thread lineage and reuse an existing thread when replying.
+ Share one typed conversation shell across direct chats and rooms.
+ Unify settings presentation, profile rows, and room information.

This release does not implement end-to-end encryption.

* 0.1.1 — 2026-08-29

First tagged alpha release on Theodora.

+ Bundle 23 color-only themes, with Rum presented as Default.
+ Apply theme selections immediately across login and authenticated interfaces.
+ Add a durable, read-only XMPP roster and direct-chat handoff.
+ Keep one persistent bottom bar ordered Roster, Home, Settings.
+ Harden reconnect, account replacement, roster lifecycle, chat navigation, and composer failure handling.

This release does not implement end-to-end encryption.
