#+TITLE: Nema - Experimental plaintext XMPP client for Android

* About

Nema is an experimental [[https://xmpp.org/][XMPP]] client for Android, built with Kotlin,
Jetpack Compose, Smack, and Room.

The current work focuses on reliable plaintext messaging: direct and group
chats, archive recovery, Carbons, replies, drafts, bookmarks, blocking,
vCards, and HTTP file upload. OMEMO and OpenPGP are not implemented. Do not
treat this build as an encrypted messenger.

Nema is alpha software. Database migrations and messaging behavior have
automated coverage, but releases may still contain bugs or incomplete UI.

* Requirements

+ Android 8.0 (API 26) or newer
+ JDK 17
+ Android SDK 36

* Build

#+begin_src sh
  ./gradlew testDebugUnitTest assembleDebug lintDebug
#+end_src

The debug APK is written to =app/build/outputs/apk/debug/app-debug.apk=.

#+begin_src sh
