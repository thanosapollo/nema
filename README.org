#+TITLE: Nema - XMPP messenger for Android

* About

Nema is an [[https://xmpp.org/][XMPP]] messenger for Android, built with Kotlin,
Jetpack Compose, Smack, and Room.

Current features include direct and group chats, archive recovery, Carbons,
replies, drafts, bookmarks, blocking, vCards, and HTTP file upload.
Development focuses on reliable messaging, responsive conversations, and
clear boundaries for future features, including legacy and modern OMEMO.

End-to-end encryption is not implemented yet. Planned OMEMO support does
not make current builds an encrypted messenger.

Nema is alpha software. Database migrations and messaging behavior have
automated coverage, but releases may still contain bugs or incomplete UI.

* Threads

The first-class thread proof is specified in
[[file:docs/threads.md][First-class threads]]. It documents Main, named threads in direct and group
chats, synchronization requirements, and what has actually been demonstrated.
Shared thread names are experimental work, not a released interoperability claim.

* Connection recovery

See [[file:docs/connection-recovery.md][Connection health and recovery]] for server probes, automatic recovery,
Reconnect controls, and the limits of background delivery on Android.

* Requirements

+ Android 8.0 (API 26) or newer
+ JDK 17
+ Android SDK 36

* Build

#+begin_src sh
  ./gradlew testDebugUnitTest assembleDebug assembleRelease lintDebug
#+end_src

The debug APK is written to =app/build/outputs/apk/debug/app-debug.apk=.
The signed alpha release APK is written to
=app/build/outputs/apk/release/app-release.apk=.
